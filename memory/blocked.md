Key rules:
1. Never omit a pending request requiring human action.
2. Do not stall workflow waiting on a pending item — keep working on unblocked items.
3. Items marked [URGENT] should be addressed first.
4. This log is automatically capped to the last 20 entries by the agent.

Example entries (delete these once the system is running):

- [YYYY-MM-DD] Human verification required for Stripe payment processing
