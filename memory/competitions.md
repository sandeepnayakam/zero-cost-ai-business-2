## Bounty/Competition Sources to Check Regularly

### Web3 Bounties (paid in crypto)
- **Gitcoin** — https://gitcoin.co — open source bounties in ETH/DAI
- **Immunefi** — https://immunefi.com — bug bounties for web3 protocols
- **Bounties Network** — https://bounties.network — decentralized bounties
- **Gitcoin Grants** — https://gitcoin.co/grants — grant rounds

### Hackathons (free entry, real prizes)
- **Devpost** — https://devpost.com/hackathons — largest hackathon directory
- **ETHGlobal** — https://ethglobal.com — Ethereum hackathons, often $100K+ prizes
- **Solana Hackathons** — https://solana.com/hackathon — regular Solana hackathons
- **Chainlink Hackathons** — https://chain.link/hackathon — Chainlink hackathons
- **Major League Hacking** — https://mlh.io — student hackathons (some online)

### Game Jams (cash prizes for games)
- **itch.io Jams** — https://itch.io/jams — many game jams, some with cash prizes
- **Ludum Dare** — https://ldjam.com — major game jam, has prizes
- **GMTK Game Jam** — annual, popular, has cash prizes

### ML/Data Science Competitions
- **Kaggle** — https://kaggle.com/competitions — ML competitions, $10K-$100K prizes
- **DrivenData** — https://drivendata.org — social-impact ML competitions
- **Numerai** — https://numer.ai — hedge fund ML competition, pays in NMR tokens

### Code Competitions
- **Code Golf** — https://code.golf — some bounties
- **Codeforces** — https://codeforces.com — competitive programming (reputation, sometimes prizes)
- **Topcoder** — https://topcoder.com — paid challenges
