What is Base58?

Base58 is a binary-to-text encoding scheme used to represent large integers as alphanumeric text. It was originally designed by Satoshi Nakamoto for use in Bitcoin to eliminate ambiguous characters like 0 (zero), O (capital o), I (capital i), and l (lower case L) while maintaining human-readable string compactness.

Common Applications

  • Bitcoin: Legacy wallet addresses and WIF private keys.
  • Solana: Public keys, wallet addresses, and transaction signatures.
  • IPFS: Content identifiers (CIDs) and peer IDs.
