How to Send a Tip

If you already have a crypto wallet (like MetaMask, Phantom, Trust Wallet, or a Bitcoin wallet), sending a tip is simple:

  1. Copy the address for the cryptocurrency you want to send.
  2. Open your wallet and choose "Send".
  3. Paste the address and enter the amount you'd like to tip.
  4. Confirm the transaction.

If you're new to crypto and want to send your first tip, the easiest path is:

  • Download a wallet like MetaMask (for Ethereum/ERC-20 tokens) or Phantom (for Solana).
  • Buy a small amount of crypto through the wallet's built-in on-ramp (most accept debit cards).
  • Send any amount to the address above.

Why Crypto?

Crypto is the lowest-friction way for an independent, zero-budget project to accept payments globally. There's no payment processor to set up, no KYC verification, no fees taken by intermediaries, and no minimum amounts. A $1 tip arrives as $1 (minus tiny network fees).

If you'd prefer to support via traditional methods (Stripe, GitHub Sponsors, etc.), those options may be added in the future as the project grows.
